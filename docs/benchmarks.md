# 数据集测试与证据

本页报告锁定的 HN3-B-R Seed-1 Epoch 8 历史实验，所有数值均能追溯到 [原始 JSON](../reports/evidence/)。这次开源整理未重新训练或重跑完整测试集。

## 1. 协议

模型来自训练 run `20260801_195609_932737`，随机种子为 `20260726`。最终轮次按三域完整验证集的 `macro_end_to_end_video_mean_precision` 重新选择为 epoch 8；报警阈值按三域验证视频 pooled F1 选择为 `0.7093930840492249`，发布入口显示为 `0.7094`。早期训练产生的 `best.pt` 使用过缓存标签选模，不能替代本次锁定的 epoch 8。

AP 为视频级 PR 排序指标；P90/P95 是召回达到至少 90%/95% 时可取得的最高精准率；`Mean-P=(P90+P95)/2`。三域宏平均对三个域等权，不等于将全部视频混在一起计算的 pooled 指标。

## 2. 三域测试：缓存特征协议

下表基于固定检测/特征提取产生的缓存、清单驱动的视频标签和同一确认器。`end_to_end_*` 是历史指标字段名称，表示包含清单内缺失样本的视频级计分口径；它不表示这一组评测运行了从视频解码到输出的完整在线链路。

| 数据集 | 清单视频数 | AP | P90 | P95 | Mean-P |
|---|---:|---:|---:|---:|---:|
| OmniFall of-syn | 2,400 | 0.8355 | 0.6837 | 0.6083 | 0.6460 |
| Fall Video Dataset | 5,241 | 0.9414 | 0.9015 | 0.8548 | 0.8782 |
| CAUCAFall | 20 | 0.9909 | 1.0000 | 0.9091 | 0.9545 |
| 三域宏平均 | — | **0.9226** | **0.8617** | **0.7907** | **0.8262** |

Fall Video Dataset 有 `8/5241` 个负视频无有效缓存窗口，统一以零分计入，而不是删除。CAUCAFall 测试只有 20 段视频，小样本域与大样本域等权使宏平均对该域波动较敏感。

固定验证阈值应用到全部 `7,661` 个测试视频后：Accuracy `0.9008`、Precision `0.8132`、Recall `0.9379`、F1 `0.8711`；`TP=2568, FP=590, TN=4333, FN=170`。该结果衡量视频级报警，不能直接转换为部署现场的每小时误报数。

证据：[OmniFall](../reports/evidence/omnifall_test_metrics.json)、[FVD](../reports/evidence/fall_video_dataset_test_metrics.json)、[CAUCAFall](../reports/evidence/caucafall_test_metrics.json)、[阈值与 pooled 指标](../reports/evidence/threshold_calibration.json)、[验证选模](../reports/evidence/validation_selection.json)。

## 3. UR Fall：无缓存在线外部评测

UR Fall 仅在方案锁定后作为外部报告：camera 0 RGB，共 `70` 段（`30` 跌倒、`40` ADL），10 FPS 因果采样，YOLO26s + ByteTrack + 确认器，无磁盘特征缓存，`max_people=1`。测试集与 UR Fall 不用于选择轮次或报警阈值。

| 项目 | 结果 |
|---|---:|
| AP / P90 / P95 / Mean-P | `0.8660 / 0.7895 / 0.7895 / 0.7895` |
| TP / FP / TN / FN | `30 / 19 / 21 / 0` |
| Precision / Recall / F1 | `0.6122 / 1.0000 / 0.7595` |
| 平均算法时延 / P95 | `44.34 / 54.53 ms` |
| 算法吞吐量 | `22.55 sampled frames/s` |
| PyTorch 峰值已分配显存 | `89.70 MiB` |

时延不包含视频解码；报告记录 `3994` 个计时采样帧，原视频采样共 `4004` 帧。上述显存是框架已分配张量峰值，不是完整进程显存或端侧峰值存储。桌面 CUDA 结果不等于海思、瑞芯微 NPU 或 V100 实机结果。当前发布默认双人模式与此单人协议不同，需要单独实测。

证据：[UR Fall 原始在线报告](../reports/evidence/urfd_online_report.json)。报告自身未记录显卡型号，项目历史环境记录为 RTX 4070 Ti SUPER；复测时应同时保存 GPU、驱动、PyTorch 和 AMP 信息。

## 4. 模型规模与适用边界

检测器 `10,009,784` 参数，确认器（含冻结几何）`2,202,930` 参数，总计 **`12,212,714`**。报告中运行时融合后的参数数目不同，公开比较采用融合前完整模型口径。

已验证的是 PyTorch/CUDA 在线原型、模型文件完整性和演示应用。ONNX/TensorRT/NPU 整链转换、INT8 精度回归、长期视频事件级误报、红外专项泛化和目标端侧时延仍需验证。

## 5. 如何解读结果

- UR Fall 的 40 个 ADL 中有 19 个误报，高召回伴随较多正常活动误报。
- 同配置 Seed-2 的三域宏 Mean-P 为 `0.7913`、UR AP 为 `0.5916`；历史单次训练的优势尚未形成多随机种子置信结论。
- 早期 HN3-B 在部分域和固定阈值 F1 上更好；最终发布锁定并不证明 HN3-B-R 全面领先。
- 尚未在相同数据、切分和输入条件下与其他公开模型做对比。

后续产品试点宜预先固定模型和验收协议，报告事件召回、首次报警延迟、误报/小时、跨场景性能及掉线恢复，并记录人工复核流程。
