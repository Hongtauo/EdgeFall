# 方法设计

EdgeFall 的发布模型为 **EdgeFall-ST HN3-B-R Seed-1 Epoch 8**。它将同一人体检测器的视觉特征与人物框运动历史结合，用几何变化提出问题，再从人物局部和场景视觉证据中确认跌倒语义。最终融合模式是 `cross-attention-summary`。

## 1. 共享检测与空间特征

每个有效采样时刻只执行一次冻结 YOLO26s 前端。检测框经 ByteTrack 关联为人物轨迹；同次前向的 P3/P4/P5 特征用于视觉确认，不再运行第二套视频视觉主干。

| 特征 | 通道 | 用法 |
|---|---:|---|
| P3 | 128 | 与 P4 一起提取人物 ROI，保留更细的空间信息 |
| P4 | 256 | 同时参与人物 ROI 和全局场景描述 |
| P5 | 512 | 与 P4 池化结果组成全局场景描述 |

全局分支对 P4/P5 做空间池化，得到 `256+512=768` 维描述。ROI 分支从 P3/P4 做 ROIAlign，拼成 `384×3×3` 特征，再投影为视觉 Token。人物框上下文扩展系数为 `1.25`，保留身体附近的支撑物和接触区域。

P3/P4/P5 是**空间分辨率层级**；短时/长时是**历史观察跨度**。高层特征并不天然等同于某个可解释的身体部位；示意图中的彩色响应若未经实际提取，不能称作模型实测注意力或激活热力图。

## 2. 两种时间跨度

模型以 `10 FPS` 有效采样，只读取当前及过去观测。偏移 `k` 表示回看 `k/10` 秒，不是原始视频中的第 `k` 帧。

| 分支 | 短时偏移 | 长时偏移 |
|---|---|---|
| 几何 | `0,1,2,3,4,5,6,7` | `0,4,8,12,16,20,24,28,32` |
| 全局视觉 | `0,2,4,7` | `0,8,16,24,32` |
| ROI 视觉 | `0,2,4,7` | `0,8,16,24,32` |

短时分支观察约 `0.7 s` 内的快速变化，长时分支覆盖 `3.2 s` 历史，帮助区分快速失衡、主动坐卧和运动后的持续倒地。几何与两个视觉分支都包含双时间尺度，但采样密度和输入特征不同。

缓存以当前到过去保存；进入因果卷积前翻转为从过去到当前。每条分支使用膨胀率 `1,2,4` 的轻量因果时序块，借助左侧填充保持只使用历史信息。历史不足、人物漏检等情况通过有效掩码处理。

## 3. 几何 Token 为什么是 31 维

归一化人物框先变成 7 维信号：

```text
g = [中心x, 中心y, 宽, 高, 面积, log(宽/高), 下边界y]
```

每个时间槽的几何 Token 包含四组 7 维量及三个时间描述量：

| 组成 | 维度 | 含义 |
|---|---:|---|
| 当前槽的 `g` | 7 | 人物框位置和形状 |
| 相对当前观测的变化率 | 7 | 当前几何与该历史槽几何之差，按时间差归一化 |
| 相邻槽局部速度 | 7 | 相邻有效几何观测的一阶差分 |
| 相邻槽局部加速度 | 7 | 局部速度的差分 |
| 归一化年龄、相邻时间间隔、有效历史比例 | 3 | 描述非均匀采样与历史完整性 |
| 合计 | **31** | `4×7+3` |

这里的 `4` 是四组不同几何描述，`3` 是三个时间描述量，均不代表人数。短时和长时各自构造 Token，并与紧凑轨迹统计一起形成几何状态。几何编码器在最终确认器训练中冻结。

## 4. 几何条件视觉确认

两个视觉编码器分别将全局场景历史和人物 ROI 历史编码为 `128` 维摘要。几何状态投影为 Query；全局和 ROI 摘要构成两个 Key/Value Token。最终模型的四头交叉注意力在这两个视觉摘要上选择证据，而不是对每个像素或每个历史帧逐一做交叉注意力。

```text
q = 几何状态的线性投影与归一化
keys = [全局摘要, ROI摘要] + 模态位置编码
values = [全局摘要, ROI摘要]
e = MultiHeadAttention(q, keys, values)
v = LayerNorm(e + FFN(e))
z = MLP([v, q⊙v, |q-v|])
```

实现中隐层维度为 `128`，注意力头数为 `4`，FFN 中间维度为 `256`。无效视觉模态由掩码屏蔽。注意力权重描述本模型对两类视觉摘要的相对使用情况，不能直接解释为因果证明。

## 5. 预测与在线聚合

融合状态连接 `normal/falling/fallen` 阶段头、`falling/fallen` 事件状态头、onset 头，以及训练使用的动作和 control 辅助头。跌倒概率由两个事件状态联合得到；在线系统分别对人物轨迹评分，画面风险取人物最大值，视频分数取所有采样时刻的最大值。报警阈值固定为验证集选择的 `0.7094`。

当前发布默认最多确认 `2` 人。历史 UR Fall 在线效率报告使用 `max_people=1`，其时延不能直接作为双人模式的实测时延。长视频上的最大值聚合会累积误报风险，产品化需进一步评估持续报警率和事件级策略。

## 6. 实现入口

核心实现为 `edgefall_st/features/adapter.py`、`edgefall_st/models/bbox_classifier.py`、`edgefall_st/models/fygr.py` 和 `edgefall_st/runtime/fygr_online.py`。本说明依据最终提交包实现整理；源码中的其他融合模式和后续实验模块不属于此发布模型。
