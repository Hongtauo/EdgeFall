# 演示说明

Web App 在浏览器中显示视频、人物轨迹、跌倒分数和报警事件。前端使用 Vue，后端使用 FastAPI，通过 MJPEG 传输画面、WebSocket 更新分数与运行状态。

## 启动

先按[部署说明](deployment.md)安装依赖并准备模型、演示视频和回放结果。在仓库根目录的 PowerShell 中运行：

```powershell
conda activate EdgeFall-ST
.\Application\start_demo.ps1 -Mode live -PythonPath (Get-Command python).Source
```

浏览器打开 `http://127.0.0.1:8000`。Linux/macOS 的启动命令见[部署说明](deployment.md#web-app)。

`live` 模式会对采样帧实际运行 YOLO、ByteTrack 和 HN3-B-R。模型或设备加载失败时会报错。只查看已有结果时可以将启动参数改为 `-Mode replay`；回放需要对应视频和 `demo/inference/frames.csv`，不运行模型。`auto` 会先尝试实时推理，失败后回退到回放，并在页面显示原因。

## 界面内容

- **视频与人物框**：显示当前片段、人物轨迹 ID 和逐人物跌倒分数。
- **风险曲线**：显示近期采样时刻的分数变化及报警阈值，默认阈值为 `0.7094`。
- **事件列表**：记录触发的报警，可以查看并确认事件；确认操作只改变演示中的处理状态。
- **运行状态**：显示 live/replay 模式、设备、处理速度和检测、跟踪、特征池化、确认器耗时。
- **播放与设置**：支持开始、暂停、恢复、重新播放，查看片段列表，以及调整阈值和播放速度。

内置播放列表有 18 个短片段，包含跌倒、正常坐下、弯腰、床上活动等情况。视频来源和使用条件见[数据集说明](datasets.md)与[第三方材料说明](third_party.md)。源码仓库默认不包含第三方视频，需自行恢复素材。

## 观察与结果解读

播放时可以对照人物动作、分数曲线和报警时刻。输入按 10 FPS 有效采样，模型使用当前及历史信息，最多回看 3.2 秒；视频开头的历史不足由有效掩码处理。

人物分数分别计算，当前画面分数取人物最大值，视频级分数取整段视频的采样最大值。一次短暂高分就可能影响整段视频的判定，因此局部曲线变化与最终视频分数需要一起看。默认最多同时确认 2 个人物。

片段标签表示样本真值，与模型输出分开显示。回放曲线和耗时来自保存的推理记录；它们不表示当前机器正在执行模型，也不能用播放帧率估计模型速度。调整演示阈值会改变页面报警行为，正式评测应使用验证集锁定的阈值。

短片段只用于查看运行过程。已有 UR Fall 在线测试中，30 次跌倒全部检出，40 个正常活动中有 19 个误报。该测试的历史平均算法时延为 `44.34 ms`，运行于 RTX 4070 Ti SUPER、`max_people=1`，且不含解码；与默认双人演示的设置不同。完整指标和协议见[评测报告](benchmarks.md)。

## 保存与调用结果

命令行推理会写出视频级 `predictions.csv`、逐采样时刻的 `frames.csv` 和运行摘要 `summary.json`。保存结果的方法见[部署说明](deployment.md#python-与批量接口)。

App 提供 `/api/state`、`/api/config`、`/api/events` 与 `/ws/telemetry` 等接口，分别用于状态、配置、事件和实时遥测。模型级 Python 调用与输出字段见[接口说明](api_zh.md)。
